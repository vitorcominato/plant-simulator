
<p align="center">Green Thumb</p>

A simple single page built in vanillajs and webpack that helps you find your plant friend

## Demo

<a href="https://green-thumb-red-ventures.netlify.app/" target="_blank">Demo</a>

## How to run

If you use yarn

``` bash
# Install dependencies
yarn

# run application in http://localhost:8080
yarn dev
```

If you use npm

``` bash
# Install dependencies
npm install

# run application in http://localhost:8080
npm run dev
```

## How to build

If you use yarn

``` bash
# Files are avaible in public folder
yarn build
```

If you use npm

``` bash
# Files are avaible in public folder
npm run build
```
